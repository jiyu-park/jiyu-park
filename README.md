## 오늘의 문제를 내일의 기준으로

안녕하세요. **웹 개발 경험**을 바탕으로 **데이터 분석과 AI 서비스 개발** 역량을 확장하고 있는 박지유입니다.

새로운 문제를 만났을 때 임시 해결에 그치지 않고,  
**원인과 해결 과정**을 정리해 다음 작업의 기준으로 만드는 편입니다.  
낯선 기술도 직접 구현하며 이해하고, 시행착오를 통해 **더 나은 방식**을 찾아갑니다.

데이터 분석, 관광 정보 추천, 계약서 검토 서비스 프로젝트를 진행하며 데이터 처리부터 API 설계와 서비스 연동까지 경험을 넓혀가고 있습니다.

책임감 있는 실행과 명확한 소통으로, 오늘 마주한 문제를 내일의 더 나은 선택으로 연결하며 사용자에게 실질적인 가치를 주는 서비스를 만드는 개발자로 성장하겠습니다.
